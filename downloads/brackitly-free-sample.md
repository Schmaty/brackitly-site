## 1. The 30-minute refresh workflow

**Goal:** improve one underperforming listing without rewriting your entire shop.

1. Pick a listing with views but weak conversion.
2. Copy the current title, tags, first paragraph, and main image notes into a doc.
3. Run the prompt chain below.
4. Make only the best 3-5 edits, not every possible edit.
5. Log today’s baseline: views, favorites, conversion rate, price.
6. Recheck after 14 and 30 days.

---

## 2. Prompt chain: stale listing refresh

### Prompt 1 — Diagnose the listing

Paste this into ChatGPT/Claude with your listing details:

> Act as an Etsy SEO and digital-download merchandising analyst. Review this listing for a printable/digital-download shop. Identify the 5 highest-impact issues affecting search intent, buyer clarity, and conversion. Prioritize fixes that do not require creating a new product. Return: issue, why it matters, exact recommended edit, and confidence level.

Add your listing title, tags, description, target buyer, price, and product type.

### Prompt 2 — Rewrite the title without keyword stuffing

> Rewrite this Etsy title for a digital-download listing. Keep it human-readable, search-friendly, and under Etsy’s current title best practices. Preserve the core product type, buyer use case, style/aesthetic, and format. Give 5 variants, then recommend the strongest one and explain why.

### Prompt 3 — Build a balanced 13-tag set

> Create 13 Etsy tags for this digital-download listing. Mix exact-intent phrases, style modifiers, use-case searches, recipient/audience searches, and file-format terms. Avoid repeating the same root word too many times. Return the tags plus the search intent each tag captures.

### Prompt 4 — Improve the first paragraph

> Rewrite the first paragraph of this Etsy description so a buyer understands what they get, who it is for, what problem it solves, and how delivery works. Keep it clear, non-hypey, and specific. Include one version under 90 words and one under 140 words.

### Prompt 5 — Create a main-image brief

> Write a Canva/mockup brief for the main image of this digital download. Include layout, text overlay, background style, product preview, trust cues, and what not to clutter. Goal: make the product instantly understandable in Etsy search results.
